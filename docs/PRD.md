할 일 관리 앱 PRD
2026년 11월 16일 · @하이니스제이
1. Why - 목적
• 일일 할일 → 주간계획 → 1년 목표를 하나의 계층으로 연결
• 실행(할일)과 목표(1년)의 연결이 끊기는 문제 해결
• 할일 상태 변경만으로 주간 진행률 자동 반영 → 수동 집계 제거
• 드래그 앤 드롭으로 상태 변경 비용 최소화
2. Who - 타깃 사용자
• 1년 목표를 세우고 주 단위로 계획하는 개인 사용자
• 일일 할일을 칸반(todo/doing/done)으로 관리하는 사용자
• 목표 대비 주간 진척도를 수치로 확인하려는 사용자
3. User Flow
1.  1년 목표 생성
2.  주간계획 생성 → 1년 목표 선택·연결
3.  할일 생성 → 날짜 지정 → 주간계획 선택·연결
4.  일일 보드에서 할일 확인 (todo / doing / done 컬럼)
5.  할일 카드를 드래그 앤 드롭해 상태 변경
6.  상태 변경 → 연결된 주간계획 진행률 자동 재계산
7.  주간 화면에서 진행률 확인
8.  필요 시 할일 수정 / 삭제 → 진행률 자동 재계산
4. 기능 요구사항
P0 - 핵심 기능
4-1. 할일 CRUD
• 생성: 제목(필수), 날짜(필수), 상태(기본값 todo), 주간계획 ID(선택)
• 조회: 날짜별 목록, 상태별 그룹
• 수정: 제목, 날짜, 상태, 연결된 주간계획
• 삭제: 삭제 전 확인, 삭제 후 진행률 재계산
4-2. 상태 관리
• 상태 값: todo / doing / done (3개 고정)
• 할일 1개는 상태 1개만 보유
• 상태 변경 시각 기록 (updated_at)
4-3. 드래그 앤 드롭 상태 변경
• 보드 컬럼: todo / doing / done
• 카드를 다른 컬럼으로 드롭하면 상태 변경
• 드롭 즉시 UI 반영, 이후 서버 저장
• 저장 실패 시 원래 컬럼으로 롤백하고 오류 표시
4-4. 기간 구조
• 일일: 날짜 단위 할일 보드
• 주간: 주 단위 계획 (시작일·종료일, 월~일)
• 1년: 연도 단위 목표
4-5. 계층 연결
• 연결 구조: 할일 (N) → 주간계획 (1) → 1년 목표 (1)
• 주간계획 생성·수정 시 1년 목표 선택
• 할일 생성·수정 시 주간계획 선택
• 상위 항목 삭제 시 하위 항목의 연결 해제 (하위 항목 자체는 유지)
4-6. 주간 진행률 자동 반영
• 계산식: done 할일 수 / 연결된 전체 할일 수 × 100
• 재계산 시점: 할일 생성, 상태 변경, 수정(연결 변경 포함), 삭제
• 연결된 할일이 0개일 때 0% 표시
• 주간계획 화면에 진행률 바와 수치(%) 표시
4-7. 데이터 모델
• YearlyGoal: id, title, year
• WeeklyPlan: id, title, week_start, week_end, yearly_goal_id, progress
• Task: id, title, date, status, weekly_plan_id, created_at, updated_at
P1 - 추가 기능
• 1년 목표 진행률: 연결된 주간계획 진행률의 평균을 자동 계산해 표시
• 같은 컬럼 안에서 드래그 앤 드롭으로 순서 변경
• 기간 이동: 이전·다음 날짜, 주, 연도로 이동
• 필터: 상태별, 주간계획별 할일 필터
• 계층 뷰: 1년 목표 → 주간계획 → 할일 트리 조회
